# LogRiff (TypeScript)

TypeScript implementation of the LogRiff CLI.

## Setup

```bash
just typescript sync
```

## Usage

```bash
just typescript check
just typescript build
just typescript run --format json ../data/sample.log
```

Compiled output in `dist/` and installed packages in `node_modules/` are git-ignored.

See the repository root `README.md` for the full CLI specification.
